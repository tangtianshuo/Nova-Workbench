    1. **数据迁移验证 (SCHED-05, SCHED-08)**
       - localStorage 已存在旧数据:先 `localStorage.removeItem('nova-schedule')`,刷新页面

       - 今天日期格有 accent 蓝色圆形高亮

       - 点"今天"按钮,立即回到今天所在月份
       - 点"下个月",标题变下月,网格重渲染

    3. **创建日程 (SCHED-01)**
       - 在 Agenda 侧栏底部点"新建日程"按钮,弹出 ScheduleDialog,标题是"新建日程"
       - 输入标题"测试事件",日期选今天,时间保留默认,类型选"截止"(deadline),地点输入"办公室"

       - 点"创建日程",Dialog 关闭,Toast 提示"日程已创建"
       - 月历今天日期格出现新事件 chip,颜色是红色(deadline)
       - Agenda 侧栏本月列表出现该事件

    4. **编辑日程 (SCHED-02)**
       - 点击刚才创建的事件 chip,Dialog 打开,标题是"编辑日程",所有字段预填(标题/日期/时间/类型/地点/关联产品)
       - 把标题改为"测试事件-改",类型改为"会议"(meeting),清除关联产品(点 X)
       - 点"保存修改",Dialog 关闭,Toast "已保存"
       - 月历上该事件 chip 标题更新,颜色变蓝(meeting)

    5. **删除日程 (SCHED-03)**
       - 再次点击该事件,打开编辑 Dialog
       - 点左下角"删除"按钮,弹出嵌套确认 Dialog,显示"删除日程?" + 事件名 + 取消/删除按钮
       - 点"取消",返回编辑 Dialog
       - 再点"删除" → 点"删除"确认,Dialog 全关,Toast "日程已删除"
       - 月历上该事件消失

    6. **日期格点击预填 (额外便利)**
       - 点月历某个空白日期格,弹出 ScheduleDialog create 模式
       - 日期字段预填为该日期(检查 DatePickerInput value)

    7. **弱关联字段就位 (SCHED-06, SCHED-07)**
       - 验证已通过(代码层面已实现 projectId?/taskId? + type='task');此条无需 UI 验证,只需在 UAT 文件中标注"代码层就绪,Phase 7 使用"

    - Dialog 字段在 create/edit 切换时正确重置(不要出现"创建模式预填了上一个 edit 的值"Pitfall P13)
    - 删除嵌套 Dialog 的 z-index 正确叠加(不应被主 Dialog 盖住)
