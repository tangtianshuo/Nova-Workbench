# Milestone v0.3.3: 产研半落地 + 工作区入驻(RND-ROLLOUT ①层)

**Status:** ✅ SHIPPED 2026-09-04(带债收口 — Known Gaps 见文末)

## Overview

把产研中心从 mock 演示转正为真实 AI 驱动:mock 全清接 Rust 引擎、各 tab AI 按钮触发带上下文的真实 run、agent 获得真实写路径(PM CRUD 工具原生化)、工作流用户自组织(模板数据化 + 「工作流」视图)、文档工作区(Milkdown 编辑器 + 右侧常驻面板)、工作区文档摄取(纯 Rust 提取 + 批量 HITL,3/4 挂起)。

2026-09-02 优先级重定:用户澄清产品哲学(工作流用户自组织,Nova 只给参考+模板,严禁刚性 pipeline),27 挂起/28 顺延,999.6(PM CRUD)promote 为 Phase 29 第一优先,999.4+999.2 取材立项 Phase 30。
