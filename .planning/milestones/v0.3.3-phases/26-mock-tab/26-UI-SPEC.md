## Component Contracts

### 1. TabRunPanel (NEW — `src/components/rnd/TabRunPanel.tsx`)

- Placement: top of tab content area, above existing list; `Card variant="default"` compact, `rounded-[var(--radius-lg)]`, `shadow-sm`.
- Auto-expand on run start (`motion` height/opacity, spring `stiffness: 350, damping: 30`); auto-collapse ~2s after done/error to a single summary row; collapsed row remains until next run or dismissed.
- Summary row: status badge + current step one-liner (13px, truncate) + elapsed + chevron toggle (CaretDown 14, rotates) + Cancel button.
- Event list (collapsed by default): scrollable (`max-h-48`), one row per event — timestamp (11px mono `font-mono text-text-tertiary`), event kind, tool name + compact arg/result summary (13px). No markdown rendering in list rows.
- Cancel: `Button variant="danger" size="sm"`, label 取消生成. Copy confirms semantics on tooltip: 已确认落槽的产物会保留.
- waiting-for-confirmation affordance: inline link-style Button (`variant="link"`) — 打开确认队列 — dispatches existing global confirmation queue open action. NOT an embedded HITL card (locked D-05).
- One run per tab: while running, the tab's AI button is `disabled` with tooltip 本 tab 已有生成任务进行中.

### 2. Tab AI buttons (six tabs + FullDeliverablesTab + product skill)

- Existing Button patterns; each triggers `tabRunStore.startTabRun`.
- Web dev fallback (no `isTauri()`): `disabled` + Tooltip: 此功能需要桌面引擎，请使用桌面版 Nova。No mock path, no dead click.

### 3. Candidate → HITL → 落槽 (six tabs, PrdDraftDialog pattern reuse)

- Candidate confirmation card → edit Dialog (MDXEditor) → versioned commit to knowledge_docs — identical structure to Phase 16 PrdDraftDialog; extract shared candidate-flow components where PrdDraftDialog already provides them rather than re-styling per tab.
- Provenance badge: existing AI 溯源徽章 (`Badge variant="accent"`, Sparkle icon 12) on every committed deliverable.
- Dialog chrome: existing `Dialog/DialogContent/DialogHeader/DialogFooter` composition, `max-w-2xl` for editor dialogs (matches existing editor dialogs), Cancel = `variant="secondary"`, 落槽 commit = `variant="primary"`.

### 4. Animation

Existing conventions only: `whileTap={{ scale: 0.97 }}` on buttons, panel expand/collapse spring 350/30, no new motion patterns.

## Interaction Contract (locked from 26-CONTEXT.md)

1. Panel embedded in tab content area; compact summary density; expand on start, auto-collapse on finish.
2. 1 concurrent run per tab; AI button disabled while running.
3. Cancel keeps committed artifacts, voids unconfirmed candidates — communicate via cancelled-state copy, no confirmation dialog.
4. HITL cards live in the GLOBAL confirmation queue; panel links to it, never embeds cards.
5. PrdDraftDialog pattern (candidate card → MDXEditor dialog → versioned commit + provenance badge) reused verbatim for all six tabs; category mapped by deliverable code.
6. Web fallback: AI buttons disabled + tooltip; no mock data path anywhere (TAB-04 no dead paths).
7. Independent sessionId per tab run — no UI surface in chat session list (verify: tab runs must NOT appear in chat session list).
