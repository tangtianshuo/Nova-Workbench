创建 `src/ai/knowledgeRepo.ts`，`KnowledgeRepo` interface + MemoryKnowledgeRepo / SqliteKnowledgeRepo + `getKnowledgeRepo()` 单例（照 confirmationStore 模式）：

```typescript
export interface KnowledgeDocInput { docId: string; productId: string; title: string; category: string; tags: string[]; summary: string; content: string; author: string; sourceType?: 'seed'|'agent'|'user'; sourceSessionId?: string }
export interface KnowledgeHit { docId: string; version: number; title: string; category: string; tags: string[]; summary: string; productId: string; sourceType: string; updatedAt: string; score?: number }
export interface SearchFilters { productId?: string; tag?: string; since?: string }

interface KnowledgeRepo {
  upsertDoc(input: KnowledgeDocInput): Promise<KnowledgeDoc>;        // 单一写 API（MEM-04/DELIV-04 前置）
  getCurrentDocs(productId?: string): Promise<KnowledgeDoc[]>;       // superseded_at IS NULL
  listVersions(docId: string): Promise<KnowledgeDoc[]>;              // 审计用，全版本
  search(query: string, filters?: SearchFilters & { limit?: number }): Promise<KnowledgeHit[]>;
  deleteByProduct(productId: string): Promise<void>;
  rebuildFts(): Promise<void>;                                        // 兜底修复：DELETE FROM knowledge_fts + 全量重插当前版本
}
export async function searchKnowledgeHybrid(query: string, limit: number): Promise<KnowledgeHit[]>; // 便捷封装，15-02 toolLoop 已引用此名
```

SQLite 实现要点（RESEARCH Pattern 2，逐字）：
- `upsertDoc` = 两步单语句：① `UPDATE knowledge_docs SET superseded_at=$now WHERE doc_id=$1 AND superseded_at IS NULL`（旧行让位）② `INSERT INTO knowledge_docs (... version=(SELECT COALESCE(MAX(version),0)+1 FROM knowledge_docs WHERE doc_id=$1), created_at=now, updated_at=now, superseded_at=NULL)` ③ `INSERT INTO knowledge_fts(title, content, summary, tags, doc_rowid) VALUES (toFtsIndexedText 各字段, last_insert_rowid 等价 — tauri-plugin-sql 下用 SELECT seq 或先取 doc_rowid 再插)`。无事务（Pitfall 1）：失败残留最多旧版本已 superseded 但新版本缺失 → upsert 幂等重跑可修复；FTS 缺行用 rebuildFts 兜底。
- `search` 有关键词：RESEARCH Pattern 2 SQL 逐字（`FROM knowledge_fts f JOIN knowledge_docs d ON d.doc_rowid = f.doc_rowid WHERE knowledge_fts MATCH $match AND d.superseded_at IS NULL AND ($productId IS NULL OR d.product_id=$productId) AND ($since IS NULL OR d.updated_at >= $since) ORDER BY f.rank LIMIT $limit`），$match 绑定 `toFtsMatchString(query)`。
- 无关键词仅过滤：跳过 FTS，`SELECT ... FROM knowledge_docs d WHERE d.superseded_at IS NULL AND ... ORDER BY d.updated_at DESC LIMIT $limit`（锁定：filters alone 也触发搜索模式）。
- 标签过滤：结果集 JS 侧 `tags.includes(tag)`（≤50 条，最省事 — RESEARCH Pattern 2 建议）。
- `deleteByProduct`：先 `DELETE FROM knowledge_fts WHERE doc_rowid IN (SELECT doc_rowid FROM knowledge_docs WHERE product_id=$1)` 再 `DELETE FROM knowledge_docs WHERE product_id=$1`（顺序安全：残留最多孤儿 docs 不可搜）。

内存实现（Node 测试/web dev）：Map<docId, KnowledgeDoc[]> 全版本数组；search 用 `toFtsTokens` 切分 + includes 匹配 + 既有 `scoreArticle` 同款词法评分排序（语义等价 FTS，Pitfall 9）。
