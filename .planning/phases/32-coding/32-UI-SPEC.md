# Phase 32 — UI Design Contract (coding 工具地基)

> Visual and interaction contract for the diff 审批卡 (fourth confirmation host), exec 首遇询问卡, TabRunPanel progress, and repo 绑定 UI. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (project-owned Radix-based kit `src/components/ui/`, NOT shadcn) |
| Preset | not applicable — existing design system detected (`src/styles/tokens.css` + Tailwind v4 `@theme`) |
| Component library | @radix-ui/react-* wrapped in `src/components/ui/` (Button/Card/Dialog/Badge/Input/Textarea/Skeleton etc.) |
| Icon library | @phosphor-icons/react, `weight="duotone"` default, `weight="fill"` for active states |
| Font | @fontsource/geist + geist-mono (mono for diff/code/exec lines) |
| Motion | motion/react (spring 350/30 page, 400/30 cards, whileTap scale 0.97) |

**Hard rules (CLAUDE.md locked):** semantic token classes only (`bg-bg-primary`/`text-text-primary`/`border-border-subtle`/`bg-accent`); hex/`bg-white`/`text-gray-*` forbidden. `cn()` from `@/src/lib/utils` with `className` last. Desktop-compact: 14px base, `p-3` card padding, `h-8` md buttons.

**New dependency rule:** `react-diff-view 3.3.3` + `diff 9.0.0` must be `React.lazy()`-loaded inside the diff card component only (297KB chunk lesson from Phase 31 prismjs). Suspense fallback = existing `Skeleton`.

Declared values (multiples of 4, project-compact):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, badge internals |
| sm | 8px | Diff line padding-x, chip internals |
| md | 12px | Card padding (`p-3`), button gaps (`gap-2` ≈ 8-12) |
| lg | 16px | Card section spacing (`space-y-4`) |

Exceptions: Tailwind half-steps already in use (`py-1.5`, `pt-0.5`, `space-y-1.5`) follow existing confirm-card precedent — allowed for compact card internals. No new values outside the existing token scale.

## Interaction Contracts

### 1. diff 审批卡 (kind `code_edit`, fourth confirmation host)

- **Structure:** one card per file, queued — only the head-of-queue card renders fully; badge shows 「N 张待审」 (N = queue length). Pattern = existing `WorkspaceConfirmCard.tsx` (border-l-2 warning edge, elevated Card, queue count link).
- **Card content:** file path (mono, truncated with title attr) + edit kind label 「代码修改」; unified diff body (react-diff-view, 3-line context, added/removed highlight, lazy-loaded); footer buttons.
- **Actions:** 「应用改动」(primary, accent) → Rust `tools::execute` replay; 「拒绝」(secondary) → reveals inline reason `Textarea` (optional, placeholder 「告诉 agent 怎么改(可选)」) + confirm 「拒绝并说明」(danger) / skip-reason 「直接拒绝」; 「沉淀改动摘要」(ghost, icon `Bookmarks`) → routes to existing knowledge_write candidate flow (second confirmation, zero new pipeline).
- **Reject semantics copy:** 「该文件不会落盘,agent 会根据原因调整重试。」— run continues, shown as caption under the reject textarea.
- **Cancellation cascade:** when run is cancelled, pending diff cards auto-reject with audit event; card shows transient state 「run 已取消,改动未应用」 before dismissal.

### 2. exec 首遇询问卡 (kind `exec_approval` extension)

- Three-button row: 「允许一次」(primary/accent) · 「总是允许」(secondary + tooltip 「记住此命令,仅当前工作区生效」) · 「拒绝」(danger).
- Command displayed mono with 学习粒度 highlight: the learned pair (command + first arg) underlined/chip, remainder plain — makes the whitelist scope visible.
- git 危险 flag 黑名单命中: **no card**; tool fails with error text 「已拒绝:git 危险操作({flag})」 surfaced in the run stream.

### 3. TabRunPanel 扩展

- Progress row: current tool name (`code` icon + `Code`/`Terminal`/`MagnifyingGlass` duotone) + target-file chip (mono, truncated); exec shows truncated command (`maxlength ~60ch`, `title` = full command). No full parameter display.
- exec output: collapsed by default, header 「输出(尾部 N 行)」 with chevron; expanded shows mono tail lines, live refresh (tail semantics).
- Changed-files list: file chips with pending/approved/rejected status dot (warning/success/danger).

### 4. repo 绑定 UI

- Workspace with detected repo: badge in workspace header 「Repo: {basename}」(accent, `GitBranch` duotone icon 12px).
- No repo detected: no badge; tools requiring repo show inline error in run stream 「未绑定代码仓库 — 请在设置中指定 repo 目录」.
- 设置页: repo_root field (Input + browse button) under workspace settings; changing it re-binds (persisted with workspace).
- Dev mode: 「绑定 Nova 仓库(狗粮)」 one-click button in settings, visible only when `import.meta.env.DEV`.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | 「应用改动」(diff card approve) |
| Empty state heading | 「暂无待审改动」 |
| Empty state body | 「agent 修改代码时,每份文件会在这里排队等你确认。」 |
| Error state (edit 校验失败) | 「文件已变化,无法应用此修改 — agent 将重读文件后重试。」 |
| Error state (repo 越界) | 「路径超出仓库范围,已拒绝:{path}」 |
| Destructive confirmation | 拒绝 diff:「拒绝后该文件不会落盘,agent 可根据你的原因调整重试。确认拒绝?」(直接拒绝无确认;附原因路径同样无二次弹窗,textarea 即确认层) |
| Queue badge | 「另有 {N} 张待审」 |
| 沉淀 CTA | 「沉淀改动摘要」→ 成功 toast 「已存入第二大脑候选,待确认」 |
