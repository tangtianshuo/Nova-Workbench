在现有 `arrangeOnCalendar` 之后(line ~306)新增一个 wrapper `syncTaskSchedule(taskId)`,处理"deadline 可能改变"的所有场景,使调用方一处调用覆盖所有情况:

```typescript
// 自动同步任务↔日程。三种情况:
//   1. 无 deadline 且无链接        → noop
//   2. 无 deadline 但有链接        → 删除旧 event(走 deleteEvent,自动清反向 taskId)
//   3. 有 deadline 且无链接        → arrangeOnCalendar(创建+链接)
//   4. 有 deadline 且已链接,且 deadline 变了 → updateEvent 同步 date/time(不重建,保留用户对 event 的其它编辑)
//   5. 有 deadline 且已链接,但 deadline 未变 → noop
// 返回值: { action: 'created' | 'updated' | 'removed' | 'noop', eventId?: string }
const syncTaskSchedule = (taskId: string, prevDeadline?: string) => {
  const task = useTaskStore.getState().categories.flatMap((c) => c.tasks).find((t) => t.id === taskId);
  if (!task) return { action: 'noop' as const };

  const hasDeadline = !!task.deadline;
  const linkedId = task.scheduledEventId;

  // (1) 无 deadline 无链接
  if (!hasDeadline && !linkedId) return { action: 'noop' as const };

  // (2) 无 deadline 有链接 → 删除旧 event
  if (!hasDeadline && linkedId) {
    useScheduleStore.getState().deleteEvent(linkedId);
    useTaskStore.getState().updateTask(taskId, { scheduledEventId: undefined });
    return { action: 'removed' as const };
  }

  // 有 deadline: 拆分 date/time
  const [datePart, timePart] = task.deadline.split(' ');

  // (3) 有 deadline 无链接 → 新建
  if (hasDeadline && !linkedId) {
    const result = arrangeOnCalendar(taskId);
    return result.success
      ? { action: 'created' as const, eventId: result.event!.id }
      : { action: 'noop' as const }; // arrangeOnCalendar 已用 getState 校验,理论不会失败
  }

  // (4)+(5) 有 deadline 有链接 → 看 deadline 是否变化
  if (prevDeadline !== task.deadline) {
    useScheduleStore.getState().updateEvent(linkedId!, {
      date: datePart,
      time: timePart ?? '全天',
      title: task.title, // 弱同步: deadline 变更时顺便对齐 title(用户后续可在 ScheduleView 改)
    });
    return { action: 'updated' as const, eventId: linkedId };
  }
  return { action: 'noop' as const };
};
```

然后在 line ~382 的 value 对象中加入 `syncTaskSchedule`。同时把 syncTaskSchedule 加到 AppContextValue 接口(line ~162 附近,arrangeOnCalendar 签名旁边)。

const syncTimers = useRef<Record<string, ReturnType<typeof setTimeout>>>({});
const scheduleScheduleSync = useCallback((taskId: string, prevDeadline: string) => {
  const key = 'deadline-sync';
  if (syncTimers.current[key]) clearTimeout(syncTimers.current[key]);
  syncTimers.current[key] = setTimeout(() => {
    syncTaskSchedule(taskId, prevDeadline);
  }, 500); // 500ms > scheduleSave 的 400ms,确保 updateTask 已落地
}, [syncTaskSchedule]);
