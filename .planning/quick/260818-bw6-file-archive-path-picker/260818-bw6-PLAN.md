  - import `{ open }` from `@tauri-apps/plugin-dialog`,`{ isTauri }` from `@/src/lib/api`,`FolderOpen` from `@phosphor-icons/react`
  - 加 handler:
    ```ts
    const browseFolder = async () => {
      const selected = await open({ directory: true, multiple: false });
      if (typeof selected === 'string') setFolderPath(selected);
    };
    ```
  - 将"本地工作区物理路径"的 Input 包一层 flex 行:Input 占满(flex-1),`isTauri()` 时右侧渲染 `<Button type="button" variant="secondary" size="md" onClick={browseFolder}><FolderOpen size={14} weight="duotone" />浏览</Button>`;Web 模式按钮不渲染(浏览器无法取绝对路径,保持手动输入)
  - open() 抛错或用户取消时静默不动(取消返回 null)
  </action>
