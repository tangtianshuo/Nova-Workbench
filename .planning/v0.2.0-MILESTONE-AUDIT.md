## 关键 gap(必须修复)

### INT-01: KnowledgeBaseView 不接 rndStore(HIGH)

- **断点:** `src/views/KnowledgeBaseView.tsx:16-29` 用 hardcoded `DOCS` 常量 + `useState`
- **应该接:** `useRndStore((s) => s.knowledgeBase)`
- **影响:**
  - 用户在「知识库」侧栏 tab 编辑 → 刷新即丢失
  - AI `writeKnowledgeArticle` / `polishKnowledgeArticleAI` 写入 rndStore,该视图看不到
- **workaround:** 产品管理 → 知识库 tab(ProductKnowledgeTab)端到端正常
- **修复成本:** 1-2 小时(把 useState 换成 store subscription + 聚合所有 productId 的 knowledge items)

## Security 审计

### CLEAN(重要)

- **CSP 真实 restrictive** —— CLAUDE.md 里"csp: null"是 stale debt,`tauri.conf.json:30` 已实际配置
- **Capabilities 最小** —— 无 `shell:execute`、无 `fs:*`、无 `dangerousRemoteDomainIpcAccess`
- **API key 链路干净** —— OS keyring 存储 + 不缓存 AppState + 不进 JS bundle + 不写日志 + 不返回字符串
- **无 SQL 注入** —— 全部参数化
- **无 XSS sink** —— 无 rehype-raw、无 dangerouslySetInnerHTML、无 eval

### 3 个 MEDIUM(建议本里程碑内修复)

1. **`server.ts:12` 无 body size limit** → `express.json({ limit: '1mb' })`
2. **`server.ts:16` 无 Origin 校验** → DNS rebinding 风险,加 allowlist
3. **`server.ts:59` console.error 输出完整 error.message** → 可能含 key,改脱敏

这 3 条仅在 `npm start`(Web 模式 fallback)下暴露风险;Tauri 桌面包不暴露 Express 到外部。
